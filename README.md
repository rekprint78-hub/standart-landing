# StandART — лендинг

Одностраничный сайт (landing) производственной компании StandART: выставочные стенды,
декорации, арт-объекты, бренд-зоны. Тёмная тема, красный акцент, Montserrat.

- `index.html` — весь сайт (HTML + CSS + JS в одном файле, без сборки)
- `assets/` — фотографии с объектов

## Как менять контакты
Открыть `index.html`, найти блок `const CONTACT = { ... }` в самом низу файла
(секция «КОНТАКТЫ») и подставить телефон, WhatsApp, Telegram, e-mail.

## Публикация
GitHub Pages: Settings → Pages → Source: Deploy from a branch → main / (root).
